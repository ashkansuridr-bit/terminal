# طرح ساخت کلیپ ۱۲۰ ثانیه‌ای Terminal SSH

## بریف و محدوده
- مخاطب: کاربران فارسی‌زبان اندروید که از گوشی به سرورهای SSH متصل می‌شوند.
- خروجی: چهار بخش مستقل ۳۰ثانیه‌ای (هرکدام دقیقاً ۹۰۰ فریم در ۳۰fps)، ۹:۱۶، ۱۰۸۰×۱۹۲۰؛ سپس اتصال بدون مکث در یک MP4 نهایی ۱۲۰ثانیه‌ای. چهار فایل بخش هم جدا تحویل می‌شوند.
- لحن: فنی، مطمئن، پرتحرک اما خوانا. رنگ‌ها و فونت از پروژه: گرافیت `#07090c`، سطح تیره، فیروزه‌ای `#35d7ae`، سفید و خاکستری؛ Vazirmatn. حرکت‌ها از حرکت دوربین/سطح/تصویر برنامه می‌آیند، نه فلش‌زدن تزئینی.
- شواهد نمایش محصول: تصاویر `public/{form,home,terminal,settings,files}.png` بازسازی‌های وفادار به Compose و منابع فارسی برنامه‌اند، نه ضبط زنده؛ `FLAG_SECURE` جلوی capture را می‌گیرد. میزبان، مسیر و خروجی ترمینال کاملاً ساختگی هستند. محتوای هر قاب نباید به‌عنوان اتصال واقعی یا قابلیت اثبات‌نشده نمایش داده شود.
- صدا: خروجی اصلی بی‌صدا خواهد بود. BGM قبلی عمداً استفاده نمی‌شود چون هویت قطعه از روی سابقه قابل‌ردیابی نیست. در این نسخه هیچ فایل صوتی/استوک ثالثی اضافه نمی‌شود؛ در صورت ساخت صدای سنتزی، مشخصات ساخت و بی‌نیازی از مجوز ثالث ثبت خواهد شد.
- این طرح تبلیغ دسترسی فروشگاهی، امضای Production، AI داخلی یا تضمین امنیت مطلق نمی‌کند. برچسب Apache 2.0 صرفاً مجوز سورس برنامه را نشان می‌دهد؛ مجوز فیلم و رسانه‌ها جداست.

## راهنمای تصویر
- پس‌زمینه‌ی ذغالی، کنتراست زیاد، هاله‌ی فیروزه‌ای بسیار محدود، خطوط بسیار کم‌کنتراست برگرفته از theme برنامه.
- ماکاپ گوشی و محتوای صفحه فقط از بازسازی‌های فعلی استفاده می‌کنند؛ هیچ field/نتیجه‌ی جدیدی به UI برنامه جعل نمی‌شود.
- فونت فارسی Vazirmatn. URL با فونت monospaced خوانا و جهت LTR.
- حرکت‌ها مبتنی بر کارت‌های پایین و پارامترهای مستند آن‌هاست؛ انطباق با چیدمان موبایل مجاز است اما حرکت «مضمون» کارت (نور جهت‌دار، drift مستقل، موج ناهم‌فاز، توالی شتاب‌دار) حفظ می‌شود.

## Gateهای پیش از رندر / QA
1. بررسی تصاویر ورودی و تطبیق عین متن‌ها/تعداد ردیف‌ها با همان تصاویر؛ هیچ محتوا یا اطلاعات واقعی افزوده نشود.
2. چهار Composition با `durationInFrames=900` و آیدی‌های مجزا، به‌علاوه‌ی composition نهایی ۳۶۰۰ فریم در Remotion.
3. رندر بخش‌ها به چهار MP4 خاموش H.264 با ابعاد/fps یکسان، keyframe و تنظیمات سازگار برای concat.
4. بازبینی still در هر transition و هر عنوان فارسی؛ بررسی RTL/LTR، clipping و URL. جمع‌بندی زمانی نهایی با ffprobe باید ۱۲۰.۰۰ ثانیه (± یک فریم پس از concat، پیش از AAC) باشد.
5. بررسی concat lossless decode انتهایی و ابتدای هر فصل؛ هر بخش مستقل ۳۰ثانیه.
6. صدای نهایی: mute؛ no-BGM واقعی، بدون claim مجوز موسیقی. CTA افقی GitHub موجود بدون تغییر نگه داشته می‌شود.

## یادداشت QA استایل‌فریم و کات‌اوت‌ها
- چهار فریم نماینده در Remotion با `--concurrency=2` رندر و بازبینی شدند: `out/qa/long-a-100-final.png`, `long-b-337.png`, `long-c-562.png`, `long-d-787.png`. فریم‌های نمونه متن فارسی/لاتین، گوشی، marginها و خوانایی لوگو را نشان می‌دهند؛ این نمونه‌برداری جای مشاهده‌ی تمام ۳۶۰۰ فریم را نمی‌گیرد.
- قاب‌های کناری لیست برای فصل میزبان‌ها و فایل‌ها از رشته‌هایی می‌آیند که عیناً داخل PNGهای نمایشی وجود دارند؛ خارج از محدوده‌ی گوشی می‌مانند تا با UI واقعی اشتباه نشوند. داده‌ها همچنان نمونه/خیالی‌اند.
- فریم‌بندی پیش‌نمایش نشان داد تیتر و قاب گوشی در فاصله‌ی قابل‌خواندن باقی می‌مانند. بخش GitHub در قاب نهایی لینک کامل مخزن را نمایش می‌دهد و برچسب مجوز را به «مجوز سورس · Apache 2.0» محدود می‌کند.
- هشدار build غيرمانع: webpack گزارش می‌کند کش `jest-worker` نمی‌تواند `@types/node` را resolve کند؛ bundling و render still با این اخطار کامل شدند. TypeScript `npx tsc --noEmit -p tsconfig.json` پاس شده است.
