# Product design principles

The visual direction is inspired by high-quality native mobile software: calm hierarchy, restrained color, generous spacing, obvious primary actions and subtle motion. It must not copy another product screen-for-screen.

1. One dominant action per screen.
2. 44dp+ touch targets for interactive controls.
3. Turquoise is an accent, not a wallpaper.
4. Prefer progressive disclosure over dense forms.
5. Connection state is always visible and understandable.
6. Security decisions use plain language and show consequences before action.
7. Persian RTL is first-class; hostnames, commands and fingerprints remain readable LTR.
8. Routine motion should be subtle and fast; it must never block terminal work.
9. Terminal content gets maximum screen area; chrome should recede when unnecessary.
10. Accessibility and reduced-motion behavior are release requirements.
