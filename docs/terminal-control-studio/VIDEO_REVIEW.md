# بازبینی مستقل ویدیوی Terminal SSH

بازبین مستقل: Agent جداگانه، فقط‌خواندنی. خروجی بررسی‌شده: نسخهٔ BGM با نام `TerminalSSH-Promo-fa.mp4`.

- نتیجهٔ کلی: **PASS برای قاب‌های نمونه و تطبیق ادعاها**.
- زمان‌های نمونه: ثانیهٔ ۱۲ (میزبان‌ها)، ۱۷ (ترمینال)، ۲۲ (SFTP) و ۲۷ (پایان‌بندی).
- چیپ‌های معرفی زیر گوشی‌اند و روی رابط نمی‌افتند. تیترهای فارسی و متن‌های تبلیغی نمونه بدون هم‌پوشانی دیده می‌شوند؛ متن ریز داخل ماکاپ گوشی در اندازهٔ کامل کوچک است، اما ایراد مسدودکنندهٔ بازبین نبود.
- ادعاهای میزبان‌ها/نشست‌های SSH، نوارکلید، تنظیم فونت/کرسر و مرور فایل SFTP با سورس تطبیق دارند. متن AI روشن می‌کند که ابزارها روی سرور راه دور اجرا می‌شوند و برنامه AI داخلی ندارد.
- ماکاپ‌بودن صفحه‌ها، `FLAG_SECURE`، ساختگی‌بودن اطلاعات آزمایشی، مجوز جداگانهٔ رسانه، Apache 2.0 و لینک دقیق GitHub بررسی شدند. هیچ ادعای فروشگاه یا اسپانسر در پایان‌بندی باقی نمانده است.
- `ffprobe` هر دو خروجی را H.264 با ابعاد 1080×1920، 30fps و AAC stereo/48kHz گزارش کرد. هش PNG فریم‌های ثانیهٔ ۱۲، ۱۷، ۲۲ و ۲۷ بین نسخهٔ BGM و بی‌موسیقی برابر است.
- **محدودیت فنی:** نسخهٔ ffmpeg داخل محیط muxer مناسب `null`، `rawvideo` یا `framemd5` ندارد؛ بازبین و اجرای محلی decode کامل تمام فریم‌ها را تأیید نکردند. بنابراین PASS مربوط به metadata و فریم‌های نمونه است، نه decode کامل.
