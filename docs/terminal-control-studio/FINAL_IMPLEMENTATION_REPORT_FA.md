# گزارش پیاده‌سازی Terminal Control Studio Pro

## تغییرات

نوار کلید ترمینال از فهرست ثابت به مدل داده‌محور با پروفایل، تم، ویرایشگر، ذخیره‌سازی محلی، اکشن‌های نوع‌دار، ژست‌ها و موتور ماکرو تبدیل شد. کلیدها از مسیرهای موجود `SshSession` به ورودی ترمینال می‌رسند. تنظیمات در SharedPreferences اختصاصی ذخیره می‌شوند و فرمت JSON نسخه‌دار دارد.

در بازبینی، یک کلید نمایشی `F…` یافت شد که متن خالی می‌فرستاد؛ با کلید عملی F1 جایگزین شد. F1 تا F12 از کاتالوگ انتخاب کلید در دسترس‌اند.

## شواهد

- MarketDebug compile و APK assembly: موفق.
- JVM: ۱٬۰۱۰ تست، بدون شکست یا تست ردشده.
- `git diff --check`: موفق.
- Instrumentation/UI/دستگاه: مسدود، چون `adb` نصب نیست.
- APK: آزمایشی MarketDebug؛ آمادهٔ انتشار یا امضاشده با کلید Production اعلام نمی‌شود.

## محدودیت‌ها

رفتار Compose روی دستگاه، TalkBack، APIهای مختلف، بازیابی پس از مرگ پردازه و اتصال واقعی SSH هنوز با تست دستگاه تأیید نشده‌اند.
