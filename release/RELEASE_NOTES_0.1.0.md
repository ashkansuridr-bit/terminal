# Terminal SSH 0.1.0

Initial market release.

- SSH password authentication.
- Real VT100/ANSI terminal rendering with xterm-256color PTY support.
- Explicit first-use server fingerprint approval (TOFU).
- Rejects changed known host keys.
- Android Keystore-backed AES-GCM vault for sensitive temporary records.
- Copy/paste, terminal resize and software/hardware keyboard support.
- Cleartext traffic disabled, backup/device-transfer exclusions and screenshot protection.
- No ads, analytics or cloud account.
